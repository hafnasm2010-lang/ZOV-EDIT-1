# ZOV EDIT — Android Studio starter project

This is a starter Android app project. It currently supports:
- Opening an image from the phone
- Brightness, contrast and saturation preview adjustments
- Saving an adjusted JPEG copy
- Brush strokes as a visible cyan mask-guide overlay (not yet a selective/local adjustment)

Important: AI subject/sky selection and true selective masking are not implemented in this starter.
The APK is not precompiled in this package. Build it with Android Studio:
1. Install Android Studio on a computer.
2. Open this folder as a project.
3. Let Gradle sync finish (internet is needed for the first sync).
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Click the notification's Locate link. The APK is normally at app/build/outputs/apk/debug/app-debug.apk.
6. Transfer that APK to your Android phone and install it. Android may ask you to allow installs from that file manager; only install APKs you built and trust.

The app is a personal starter project, not an Adobe product.
